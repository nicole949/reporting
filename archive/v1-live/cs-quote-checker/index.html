      The checker refreshes the quote from HubSpot, recalculates the billing schedule (quantity × unit price × periods per line item, total contract value, first payment), runs deterministic rule checks and then lets Claude review the quote against the full text of the Quote & licence rule set (source of truth; rule IDs such as L-01 point to it), the Revenue Hub / Quoting Documentation and 5.5 Services pages. Every result records the documentation versions it was checked against · Findings are grouped: deal/pipeline/template first (decides the rest), then missing properties, line items, amounts, deal & company data, presentation · Severity: red = must not go out, amber = fix before sending, teal = check · Score: 100 − 25 per red − 10 per amber finding, each root cause counted once · Column and totals settings are not exposed by HubSpot, so the page shows the recommended setup (T-03) instead of findings · Not checked: payment terms, executive summary, quotas written into descriptions · Quotes are mirrored hourly; the reload link fetches them immediately.
